# Contributing to Tala

Welcome! Start with the [external contributor guide](Documents/Contributing/README.md). It covers a first checkout,
toolchain setup, component ownership, tests, style and licensing, and pull-request preparation.

The [cross-component contribution contract](Documents/CONTRIBUTING.md) and public [`Spec/`](Spec/README.md) remain
important references. Tala is experimental: a language-design example does not imply that the current compiler
implements it. Please include a focused test and describe what is connected today.

For a security vulnerability, do not open a public issue or paste private data. Contact support@progmasoft.com.
